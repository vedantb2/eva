# React Doctor false positives

- `src/routeTree.gen.ts` — generated by TanStack Router; do not edit `eslint-disable` comments.
- `react-hooks-js/todo` — React Compiler unimplemented lowering (try/finally, etc.); not an app defect. Prefer rewrite when cheap; otherwise treat as compiler limitation after validating the help text.
- `react-hooks-js/incompatible-library` on TanStack Table views — library returns non-memoizable functions; `"use no memo"` is the supported escape hatch.
